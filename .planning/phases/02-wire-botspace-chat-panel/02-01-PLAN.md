**2. Add escapeHtml() utility function** (before loadChat):
```javascript
function escapeHtml(str) {
    if (str == null) return '';
    const div = document.createElement('div');
    div.textContent = String(str);
    return div.innerHTML;
}
```
This uses the browser's own text-to-HTML encoding per OWASP recommendation. It converts `<script>` to `&lt;script&gt;`, etc.

**4. Rewrite loadChat() entirely** (replace lines 478-495). The new implementation must:
- Fetch from `FACEBOT_URL + '/api/feed'` (NOT from `news-cache/feedback.json`)
- On success: reset `chatBackoff = 5000`
- Reverse the messages array (FaceBot returns DESC order, chat needs ASC -- oldest at top)
- Render messages using template literals with `escapeHtml()` on ALL dynamic content: `msg.content`, `msg.name`, `msg.username`
- Use field `msg.content` (NOT the old `msg.message` -- the stub had wrong field name)
- Use field `msg.name || msg.username` for display name (NOT the old `msg.user`)
- Apply CSS class `alert` when `msg.type === 'Alert'` (capital A, matching FaceBot's type field)

- Auto-scroll: check if user is near bottom before updating (`feed.scrollHeight - feed.scrollTop - feed.clientHeight < 50`), only auto-scroll if true OR if this is a fresh load
- On catch (any error): set `feed.innerHTML` to a chat-msg with class alert containing "FACEBOT OFFLINE" from SYSTEM user
- On catch: apply exponential backoff: `chatBackoff = Math.min(chatBackoff * 2, 60000)` (doubles up to 60s max)

function scheduleChatPoll() {

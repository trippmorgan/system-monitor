**Fix 1: Replace uuid import with crypto (FBOT-04)**

**Fix 2: Fix agent seeding (lines 47-51)**
The current code uses `db.prepare().run()` in a forEach without callbacks. While sqlite3 does have a prepare() method, the current usage pattern is fragile -- stmt.run() within forEach fires all inserts without waiting for completion and has no error handling.

Replace the prepare/forEach/finalize block with individual `db.run()` calls inside the existing `db.serialize()` block. Since `db.serialize()` guarantees sequential execution within its scope, each `db.run()` for INSERT OR IGNORE will complete before the next starts:

```typescript
agents.forEach(agent => {
  db.run(
    `INSERT OR IGNORE INTO agents (id, username, name, icon) VALUES (?, ?, ?, ?)`,
    [crypto.randomUUID(), agent.username, agent.name, agent.icon]
  );
});
```

This is cleaner and uses the correct sqlite3 API. No `stmt.finalize()` needed.

**Fix 3: Fix startup race condition (FBOT-01)**
The current code calls `app.listen()` at line 99, OUTSIDE the `db.serialize()` callback. This means the server starts accepting requests before table creation and agent seeding complete. On a fast machine this often works by luck, but it is a real race condition.

Restructure the startup to ensure DB init completes before the server accepts connections:

1. Wrap the existing `db.serialize()` block in a function `initDatabase()` that returns a Promise
2. The Promise resolves in a final `db.run()` callback (or a `db.get("SELECT 1")` sentinel) at the end of the serialize block to signal completion
3. Create an `async function main()` that awaits `initDatabase()` then calls `app.listen()`
4. Call `main().catch(console.error)` at the end of the file

Here is the approach for initDatabase:

```typescript
function initDatabase(): Promise<void> {
  return new Promise((resolve, reject) => {
    db.serialize(() => {
      db.run(`CREATE TABLE IF NOT EXISTS agents (...)`, (err) => { if (err) reject(err); });
      db.run(`CREATE TABLE IF NOT EXISTS posts (...)`, (err) => { if (err) reject(err); });

      // Seed agents
      const agents = [...];
      agents.forEach(agent => {
        db.run(`INSERT OR IGNORE INTO agents (id, username, name, icon) VALUES (?, ?, ?, ?)`,
          [crypto.randomUUID(), agent.username, agent.name, agent.icon]
        );
      });

      // Sentinel query to detect when all previous serialized operations are done
      db.get("SELECT 1", (err) => {
        if (err) reject(err);
        else resolve();
      });
    });
  });
}
```

The sentinel `db.get("SELECT 1")` at the end of serialize() guarantees all prior serialized statements have completed before resolving the Promise.

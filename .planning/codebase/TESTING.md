## Mocking

**Framework:** Not used - no external mocking library

**Patterns (Bash):**
- Error handling via redirects: `2>/dev/null` suppresses actual errors
- Graceful degradation: `command -v tool &>/dev/null || echo "not found"`
- Mock data in JavaScript: Dashboard shows "Offline - Using Mock Data" on fetch failure

**What to Mock:**
- External commands that may not exist: `nvidia-smi`, `jq`, `systemctl`
- Network failures: Try/catch in JavaScript returns empty state
- File system issues: Fallback to defaults when files missing

**What NOT to Mock:**
- Core system utilities: `bash`, `awk`, `curl`, `python3` (required)
- File system operations: Tests read actual /proc, /sys, df output
- Network I/O: Real curl requests to news sources

## Test Types

**Unit Tests:**
- Not formally implemented
- Implicit unit testing: Each script can be run independently
- Example: `./dashboard/system-stats.sh` generates JSON output

**Integration Tests:**
- `validate.sh` runs 47 integration-style checks:
  - Dependency availability checks
  - Configuration parsing checks
  - Directory structure validation
  - Script executability verification
  - Basic functionality tests (reading /proc, /sys, etc.)
  - Port availability check

**E2E Tests:**
- Not formally implemented
- Manual testing: `launch.sh` starts full system and can be verified in browser
- Dashboard loads news and stats successfully = E2E pass

**Smoke Tests (Implicit):**
- `launch.sh` performs initial data fetch before starting server
- If fetches fail silently, dashboard loads with empty state
- Browser open attempt validates basic system capability

**Error Testing (Bash):**
```bash
# Graceful error handling with fallbacks
if [ -f "$CONFIG_FILE" ]; then
    source "$CONFIG_FILE"
else
    echo "Warning: config.sh not found, using defaults" >&2
    # Set defaults inline
    LOG_DIR="$HOME/system-monitor/logs"
fi

# Command availability testing
if command -v nvidia-smi &> /dev/null; then
    GPU_INFO=$(nvidia-smi --query-gpu=... 2>/dev/null)
else
    echo "No NVIDIA GPU detected"
fi
```

**State Comparison Testing:**
```bash
# Change-based alerting pattern (system-monitor-assistant.sh)
LAST_STATS=""
while true; do
    CURRENT_STATS=$(get_current_stats)

    if [ "$CURRENT_STATS" != "$LAST_STATS" ]; then
        compare_and_alert "$CURRENT_STATS"
        LAST_STATS="$CURRENT_STATS"
    fi

    sleep $CHECK_INTERVAL
done
```
